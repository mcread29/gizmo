## Priority Issues

- [P1] Contrast: accent #d54f35 at 4.20:1 (links, active thread titles, palette labels); text-faint #7d8375 at 3.76:1 carrying 11px metadata (timestamps, session sub-labels, elapsed). Fix: darken accent to ~#c43f26; move semantic metadata to text-muted.
- [P1] 10px type in editor.css:109 (attachment chips), command-palette.css:83, workspace-picker.css:232 — below the documented 11px floor. Fix: var(--text-2xs).
- [P1] Phantom token var(--space-7) in workspace-dashboard.css:189 — margin silently resolves to 0; Threads list hugs facts strip. Fix: var(--space-6) or define token; grep for others.
- [P2] Thread deletion has no undo/reassurance (vs scoped Restore-defaults dialog). Fix: optimistic delete + 6s Undo toast, or message count in confirm copy.
- [P2] Failures quieter than their importance: tool error text behind a click; no "run interrupted" marker after mid-stream refresh; dead ConversationPlaceholder.svelte second empty-state system; thin thread-empty. Fix: inline error text on data-state=error, interrupted marker, delete dead component, workspace-aware empty state.
