# Product

## Register

product

## Users

Developers working with an AI coding agent inside an active repository. They need to manage threads, inspect workspace and Git state, choose models, invoke agent capabilities, and steer implementation without leaving their coding workflow.

## Product Purpose

Gizmo provides a complete browser-based frontend for Pi. It combines Pi's agent runtime, tools, extensions, skills, prompts, models, and authentication with a persistent workspace shell, thread management, Git integration, settings, and structured tool presentation. Success means the interface stays out of the way while making the agent's state and capabilities easy to discover and control.

## Brand Personality

Focused, capable, quiet. The product should have the restraint and confidence of tools such as Linear and Raycast without imitating their visual identity.

## Anti-references

- Consumer-chatbot styling with oversized bubbles, playful gradients, or assistant mascots
- Overloaded IDE density with tiny controls, visual noise, and every option exposed simultaneously
- Generic SaaS dashboards built from decorative cards, metrics, and marketing chrome

## Design Principles

1. Keep the workspace and current task central; controls should recede until relevant.
2. Make powerful agent capabilities discoverable without permanently increasing visual density.
3. Prefer familiar, keyboard-efficient product patterns over novel interaction for its own sake.
4. Expose meaningful runtime state and outcomes instead of decorative status.
5. Preserve continuity across threads, workspaces, models, and agent actions.

## Accessibility & Inclusion

No formal conformance target is required right now. Preserve existing keyboard navigation, visible focus behavior, semantic controls, readable contrast, and reduced-motion support as the interface evolves.
