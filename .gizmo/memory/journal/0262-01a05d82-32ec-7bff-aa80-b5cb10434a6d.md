- All static and runtime inspector tabs are rendered as peers.

- Added an app-owned empty state when no inspector UI is enabled.

### Unity migration

- Unity now contributes a normal **Unity** inspector tab.
- **Console**, **Subagents**, and **Workflows** are sibling tabs.
- Removed Unity’s nested Status/Console navigation.
