## What gizmo is

A pnpm monorepo desktop/web agent app wrapping the Pi coding agent.

- `apps/app` — Svelte 5 (runes) + Vite frontend, packaged as a Tauri desktop app (`apps/app/src-tauri/`). Entry `apps/app/src/App.svelte`.
- `apps/agent-server` — Node/TypeScript backend. Not HTTP/REST: it's a **WebSocket JSON request/response protocol** (`apps/agent-server/src/transport/websocket-server.ts`, router at `transport/request-router.ts`).
- `packages/protocol` — TypeBox schemas shared by both sides (request envelopes, responses, parsers).
- `packages/ui`, `packages/design` — component/design system; `packages/extensions` — Gizmo server extension API.
- Docs worth reading: `docs/resources.md`, `docs/project-configuration.md`, `docs/pi-default-system-prompt.md`.
