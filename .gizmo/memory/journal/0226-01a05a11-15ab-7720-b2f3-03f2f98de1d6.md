what else does ui-customization do?

## assistant

`ui-customization` does the following:

### In Pi’s terminal TUI

- Replaces the header with animated blue-gradient Pi ASCII art.
- Displays the current working directory as the subtitle.
- Replaces the footer with:
  - Current directory
  - Provider and model
  - Thinking level
  - Context usage and context-window size
  - Session cost
  - Generation speed in tokens/second
  - Git branch
  - Number of changed files
  - Linked GitHub PR, when available
  - Statuses published by other extensions
- Removes the **Themes** section from the interface.
- Updates the terminal/window title to `pi · <directory>`.

### In Gizmo/RPC mode

It does not install the custom header or footer. Instead, it publishes one combined semantic status containing:

- Model and provider
- Thinking level
- Context usage
- Session cost
- Git branch
- Changed-file count

It also sets the Pi session title. Most of its visual customization is therefore TUI-only; Gizmo receives the status summary rather than the custom layout.
