So every tab gets its own agent service, project services, and extension host, all destroyed on disconnect. Consequences of the wrong model:

- **Tab close = agent death** (the thing that bit you)
- **Two tabs can't see the same session** — each connection has a private `AgentEventHub`, so events from one tab's session never reach another

1. **One `PiAgentService`, one `ProjectServiceRegistry`, one `ExtensionHostService`** created once in `server.ts`, owned by the server's lifetime.
