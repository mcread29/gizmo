## Overall Impression

This UI is quietly excellent at the thing that matters most for an agent frontend: runtime state is the decoration. Every colored pixel maps to a real condition. ## What's Working

1. **State-as-decoration discipline.** `StreamingIndicator` counts elapsed seconds ("a long Unity compile behind a static label reads as a hang; count it out"), pulsing dots mark working threads, the titlebar center swaps dead metadata for streaming activity. You could paint the whole app grayscale and still know what's happening.
2. **The focus system** (`primitives.css`). `:focus-visible` rings everything by default (opt-out, not opt-in), and `:focus-visible { position: relative; z-index: 1 }` with the comment "Rings must never be clipped by an overflow ancestor" fixes a bug most design systems ship with forever.
3. **ConfirmDialog's defaults** (`packages/ui`): Cancel renders first *and* takes focus — "a modal whose only button is the destructive one is a misclick away from data loss."

## Priority Issues

**[P1] Contrast failures on real content** — `--color-accent #d54f35` is **4.20:1** on white, used for markdown links, active thread titles, and palette-selected labels at 12–14px (AA needs 4.5:1). **[P1] Type floor violations: 10px text in three shipped styles** — `composer-parts/editor.css:109` (attachment chips), `dialogs-parts/command-palette.css:83` (palette footer kbd), `dialogs-parts/workspace-picker.css:232` (empty state). `tokens-base.css` literally comments "11px is the floor."
