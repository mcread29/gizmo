## user

where would be the best place for the registry to be cloned to

## assistant

Best: keep registry clones under Gizmo’s own data directory:

```text
~/.gizmo/registries/<registry-name>/
```

For example:

```text
C:\Users\mchan\.gizmo\registries\gizmo-registry\
```

That cleanly separates:

- **Gizmo-managed source clones:** `~/.gizmo/registries/`
- **Pi backend discovery links:** `~/.pi/agent/extensions/`
- **Gizmo browser bundle links:** `~/.pi/agent/extension-web/`

The current `~/.pi/agent/extensions-src/` works, but implies Pi owns the clones. Gizmo owns registry cloning/building/linking, so `.gizmo` is the clearer boundary.
