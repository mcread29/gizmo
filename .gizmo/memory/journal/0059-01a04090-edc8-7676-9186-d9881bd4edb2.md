### Added

- Global resources now use `~/.pi/agent` and `~/.agents`, including `PI_CODING_AGENT_DIR`.
- Skills can be edited as validated Markdown from **Settings → Agent**.
- Skill writes are atomic, size-limited, and reject unsafe symlink paths.
- Pi extensions can be globally enabled/disabled without deletion:
  - Enabled: `~/.pi/agent/extensions`
  - Disabled: `~/.pi/agent/extensions-disabled`
- Normal Gizmo and Pi Web sessions now use the same managed resource selection.
- Existing per-project skill overrides remain supported.
- Extension providers register before initial model selection.
- Updated protocol, client/server APIs, UI, tests, README, and `docs/resources.md`.

The UI follows the progressive-disclosure patterns seen in pstack, Matt Pocock’s skills, and Ben Davis’ setup: compact catalog rows, provenance/path details, and raw files only when editing.
