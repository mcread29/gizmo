## What changed in the toolbar

`ComposerToolbar.svelte` moved the danger "Stop response" button out of the `composer-send` cluster to the far left, beside Attach. The send cluster is pinned right by `margin-left: auto`, so Stop is now the maximum distance from the button you actually aim for. Stop is still there while streaming — just not where a slip lands on it.

The integration test now asserts the arrangement structurally rather than just checking both buttons exist:

```ts
expect(document.querySelector('[data-ui="composer-send"]')).toContainElement(steerButton);
expect(document.querySelector('[data-ui="composer-send"]')).not.toContainElement(stopButton);
```

So a future refactor that drifts Stop back into the send position fails the suite instead of quietly re-arming the hazard.
