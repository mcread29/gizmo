### reasoning

Pi extension "global enable" is implemented by moving folders between `extensions/` and `extensions-disabled/` in the agent dir. So a per-project override of Pi extension enablement can't piggyback on that mechanism directly — it would need Gizmo-side project state (e.g., in `.gizmo/config.json`) that filters which Pi extensions get loaded for sessions started in that workspace.
