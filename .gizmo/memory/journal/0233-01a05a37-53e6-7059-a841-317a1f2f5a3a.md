## assistant

Because registry skills are intentionally classified as **not editable**:

- `resource-catalog.ts` only sets `editable: true` for skills inside Gizmo’s managed skill roots.
- Registry extensions are junction-linked from a Git clone, so their skills fall outside those roots.
- `SkillList.svelte` disables selection whenever `skill.editable` is false, which also prevents **viewing**—that part is unnecessarily restrictive.
- Server writes also reject symlinked/junction-backed files to avoid modifying the registry checkout and causing update conflicts.

The right behavior is: **all skills should be viewable, while registry skills remain read-only**. Editing should require copying/forking the skill into a managed skills directory.
