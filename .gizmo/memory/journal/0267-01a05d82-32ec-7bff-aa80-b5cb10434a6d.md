## assistant

The purpose is to remove the remaining assumption that one extension—currently Unity—owns workspace/project behavior.

Today, core code has one `projectStatus` and chooses the first project service. That works for Unity alone but breaks when multiple enabled extensions need independent status or launch behavior.

The protocol change would let:

- Unity report Editor status.
- Git report repository status.
- Another extension report its own service status.
- Each extension expose its own open/start operation.
- Multiple services coexist without priority or ownership rules.

In short: workspace context stays app-owned, while extension-specific state and operations remain extension-owned.
