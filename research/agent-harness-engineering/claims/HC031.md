# [HC031] Replay is safe only within its recorded deterministic boundary.

- **Claim text:** A replicated or write-ahead event log can recover controlled state, but safe replay of an agent run requires recorded external observations and suppression/reconciliation of side effects; reissuing live calls can duplicate effects or observe a different external world.

- **Polarity:** qualifies
- **Scope:** crash recovery, state-machine replay, and agent event logs interacting with mutable external services
