# [HC026] Retry safety requires end-to-end operation identity and effect-coupled duplicate state.

- **Claim text:** Safe retries of a non-naturally-idempotent operation require a stable logical operation identity, durable duplicate/completion state at the authority performing the effect, and atomic coupling between that state and the protected effect; transport retry or a request ID stored only in the harness is insufficient.
- **Claim type:** synthesis
- **Polarity:** supports
- **Scope:** retried RPC/API operations and logical side effects within the participating authority's atomicity and retention boundaries
- **Claim status:** supported
