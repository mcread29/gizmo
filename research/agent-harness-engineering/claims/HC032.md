# [HC032] Exactly-once claims are conditional on a named effect and failure model.

- **Claim text:** An exactly-once claim is meaningful only when it names the semantic effect and states assumptions for stable identity, durable duplicate/result retention, atomic coupling, ownership/linearizability, crash and Byzantine failures, retention/reclamation, and every downstream participant.
