# [HC025] A timeout can leave a side-effecting tool call with an unknown outcome.

- **Claim text:** When a request may have reached a side-effecting tool but no response is received, the harness cannot infer non-execution; the effect may be absent, pending, applied once, or—after retries—applied more than once.
- **Claim type:** descriptive
- **Polarity:** supports
- **Scope:** request/response tool and API calls under loss, delay, crash, and retry; application to LLM harnesses is conditional on the tool protocol matching these failure models
- **Claim status:** supported
- **Owner:** agent-harness-engineering review
