# [HC027] Atomicity stops at the boundary of enlisted transactional resources.

- **Claim text:** A harness cannot make a multi-tool workflow atomic merely by naming it a transaction: strict commit/rollback covers only state controlled by one transaction manager or participating resource managers; unmediated external effects require staging, an endpoint protocol, compensation, or explicit partial-commit handling.
- **Claim type:** synthesis
- **Polarity:** supports
- **Scope:** workflows spanning local state and independently administered tools/APIs; crash-failure semantics unless a source states otherwise
- **Claim status:** supported
