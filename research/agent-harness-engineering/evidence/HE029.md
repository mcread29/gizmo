## Result

- **Metric, estimate, and units:** token use rose with release order (Spearman rho=0.743, p<0.0001); the first nine releases averaged about 391K tokens/task and the latest releases about 668K, over 70% more, without a corresponding significant resolve-rate trend
- **Denominator / sample size:** 35 releases × 50 tasks × 2 runs = 3,500 executions
- **Runs / seeds / sampling:** two runs per release/task; seed details unknown/not retained
- **Dispersion / confidence interval:** correlation p-value reported; confidence interval unknown/not retained
