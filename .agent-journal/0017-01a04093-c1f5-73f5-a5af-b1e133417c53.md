## Current public setup

Matt Pocock’s canonical public collection is **[`mattpocock/skills`](https://github.com/mattpocock/skills)**, MIT-licensed and currently packaged as **25 promoted skills**.

Two installation modes:

- Managed Claude Code plugin: `claude plugins install mattpocock-skills`
- Editable, cross-agent files: `npx skills@latest add mattpocock/skills`

After installation, users run `/setup-matt-pocock-skills` once per repository to configure issue tracking, triage vocabulary, and domain-document layout.

Sources: [repository/README](https://github.com/mattpocock/skills/blob/main/README.md), [official skills site](https://www.aihero.dev/skills), [plugin manifest](https://github.com/mattpocock/skills/blob/main/.claude-plugin/plugin.json)

## Notable UX and features

- **A visible idea-to-ship spine:** `/grill-with-docs` → `/to-spec` → `/to-tickets` → `/implement` → `/code-review`. The site organizes skills by when users need them, rather than alphabetically.
- **Router command:** `/ask-matt` recommends the appropriate workflow, reducing command-discovery burden.
- **Recommended answers during interviews:** grilling presents numbered questions, separators, and an explicit recommended answer. Questions are asked in dependency-aware rounds rather than all at once.  
  [Grilling skill](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md)
- **Human/model invocation split:** orchestration commands are human-only; reusable disciplines may be selected automatically by the model. This distinction is represented for both Claude and Codex.  
  [Invocation conventions](https://github.com/mattpocock/skills/blob/main/.agents/invocation.md)
- **Progressive disclosure:** core steps remain in `SKILL.md`; branch-specific rules, templates, and references live in sibling files and are loaded only when needed.

## File conventions worth borrowing

```text
skills/<bucket>/<skill-name>/
  SKILL.md
  agents/openai.yaml
  optional reference files
  optional scripts/templates

docs/<bucket>/<skill-name>.md
```

Additional conventions:

- Buckets distinguish `engineering`, `productivity`, `in-progress`, `deprecated`, and other non-promoted work.
- Every promoted skill appears in the top-level README, bucket README, plugin manifest, and mirrored human-facing docs.
- `SKILL.md` uses YAML frontmatter with `name`, trigger-oriented `description`, and optionally `disable-model-invocation`.
- `agents/openai.yaml` carries picker labels and Codex implicit-invocation policy.
- Human docs consistently use: **What it does**, **When to reach for it**, **Common questions**, **It’s working if**.
- Changesets and a version-sync script treat prompt behavior like a versioned product.
- `AGENTS.md` is a symlink to `CLAUDE.md`, avoiding duplicated repository instructions.  
  [Repository conventions](https://github.com/mattpocock/skills/blob/main/CLAUDE.md)
