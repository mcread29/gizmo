- direct extension `localStorage`, which duplicates error handling and breaks global reset/migration;
- project configuration, which would incorrectly commit a personal Play Mode preference to the workspace;
- server persistence, which adds protocol/file work for a browser/device preference.

Do not bump the storage key. Reading the legacy field and writing only the new nested field provides an automatic one-save migration.
