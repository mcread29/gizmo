fix

1. **Unsaved work can still be lost.** The confirmation only covers selecting another skill; settings navigation, workspace navigation, refresh/unload, or uninstalling the active skill can destroy edits without warning.

2. **Mobile does not provide a practical full editor area.** The large settings navigation, stacked library (`340px`) and fixed `560px` editor push editing far below the fold. Use a narrow-screen library/editor master-detail view and `100dvh` sizing.

3. **The empty state misreports loading/availability.** Before resources arrive, it can show “0 of 0 on” and “No skills match.” Distinguish initial loading, genuinely empty libraries, filtered results, and connection errors.

4. **Search has no visible keyboard focus.** The input removes its outline, but the wrapper has no `:focus-within` treatment.

5. **Editor state is insufficiently announced.** Selected rows expose selection only through `data-selected`; loading, save errors, and unsaved status lack appropriate `aria-current`/`aria-live`/alert semantics.
